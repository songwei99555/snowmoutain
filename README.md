# 3D 冰雪山谷 (Winter Mountain Valley 3D)

基于 Three.js 实现的高沉浸感 3D 山谷下雪场景。

## 功能亮点

1. **程序化山谷与冰川地形**
   - 采用多重分形布朗运动 (FBM) 与山脊算法 (Ridged Noise)，程序化生成连绵险峻的山峰与蜿蜒平缓的中央峡谷。
   - 智能斜率坡度着色：平缓山顶与谷底覆盖厚重纯净白雪，陡峭岩壁露出深灰/墨黑色的玄武岩石与冰蚀岩层。
   - 谷底铺设带有镜面反光与微透明质感的冰封河流（Frozen River）。

2. **植被与环境细节**
   - 使用 `InstancedMesh` 批量实例化渲染 2,200+ 棵覆雪冷杉/松树与数百块积雪巨石，兼具视觉丰富度与流畅 60FPS 极佳性能。
   - 树木根据地形坡度与海拔自适应分布在谷底两侧及半山腰。

3. **双层动态风雪粒子系统**
   - **主雪花层**：18,000 片 3D 雪花，具备独立下落速率、初相位与微风轻微扰动。
   - **风雪雾气层**：4,000 粒贴地低空飘雪尘埃与暴风雪烟雾，营造严寒冷冽的真实暴风雪氛围。
   - 程序化动态生成软羽化发光径向雪花贴图，零外部图片依赖。
   - 边界无缝自动循环与回卷，确保降雪永续连贯。

4. **动态天气与光照系统**
   - **冬日暖阳 (Alpine Dawn)**：低角度金粉色破晓晨光，雪地拖出幽长冷蓝阴影。
   - **阴云风雪 (Winter Blizzard)**：苍茫暗沉的严冬雪雾天气。
   - **极光冬夜 (Polar Aurora Night)**：幽深极夜，天际闪烁翡翠绿与紫罗兰相间的飘渺极光，清冷月光照亮雪山。
   - 远处环形雪山天际线剪影与柔和雾化，打造开阔深邃的空间景深。

5. **沉浸式交互控制**
   - 降雪强度调节：轻柔细雪、纷飞大雪、呼啸暴雪。
   - 实时风速与风向滑块控制。
   - 4 种经典视角一键切换：峡谷全景、谷底穿行、半山雪松、雪峰俯瞰。
   - **电影级自动漫游运镜**：沿峡谷样条曲线自动平滑穿梭巡航。
   - **原生风雪环境音效**：基于 Web Audio API 纯原生合成真实风雪呼啸声，无需加载外部音频文件。

## 启动与验证方法

### 方式 1：使用 Python 内置 HTTP 服务（推荐）
在当前目录下运行：
```bash
python3 -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`

### 方式 2：使用 Node.js / npx
```bash
npx serve -l 8080 .
```
然后在浏览器中访问：`http://localhost:8080`

### 方式 3：直接打开 HTML
现代支持 Import Map 的浏览器（Chrome 89+、Edge 89+、Firefox 108+、Safari 16.4+）启动本地静态服务即可直接体验，所有依赖已内置在 `libs/` 中，无需联网。
